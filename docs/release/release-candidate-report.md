### Overall Clinical Go/No-Go recommendation: **NO-GO**

Clinical go-live must not proceed. The software and the Windows installer are verified as far as one developer machine can verify them, but critical hospital acceptance items are untested or unsigned: HIS integration on the hospital network (Q-I3/Q-I4/Q-I5), reboot and SYSTEM-account behaviour on the hospital host, backup/DR on hospital infrastructure, staff UAT, DCC/Clinical Governance approvals and the physical label test. Migrations 099–104 are approved for synthetic/test databases only; applying them to an operational database needs an Owner-authorised procedure with a verified backup first.

### Recommended order of work (each step needs the named authorization)

1. IT provides an explicitly authorized non-production host and administrator access; run `windows-installation-runbook.md` §2–§4 (closes G-07/G-08/G-09/G-12).
2. IT/HIS provides a non-production receiver and written answers to Q-I3/Q-I4/Q-I5; run `his-acceptance-plan.md`.
3. IT installs the NAS destination, key escrow and schedule; run `backup-dr-runbook.md` BDR-01…13 and a drill on production-sized data.
4. Execute the UAT checklist with the named roles, including the physical label test; obtain DCC and Clinical Governance decisions.
5. Only then ask the Owner for a Go decision and, separately, authorization for a production installation and Production migration.
