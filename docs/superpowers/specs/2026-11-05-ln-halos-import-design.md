# นำเข้า LN Halos สำหรับตัวอย่างรอเข้าห้องปฏิบัติการ

## เป้าหมาย

นำเข้าไฟล์ Excel ที่มีคอลัมน์ `LN` และ `LN Halos` ซึ่งออกเลขจากภายนอก โดยเก็บคู่เลขเดิม จับคู่ PET ที่มีอยู่แล้วหรือมาภายหลัง และให้ตัวอย่างที่จับคู่สำเร็จแสดงสถานะ **รับจาก HIS** พร้อมดำเนินงานต่อใน Task List ตามเงื่อนไขที่มีอยู่

## แนวทาง

ใช้เส้นทางนำเข้าคู่เลขสำหรับงานที่ยังต้องทำในห้องปฏิบัติการ โดยนำความสามารถตรวจไฟล์ การเก็บหลักฐาน การสงวนเลข และการรับ PET ที่มีอยู่กลับมาใช้ตามความเหมาะสม เส้นทางนำเข้าผลย้อนหลังเพียงอย่างเดียวไม่ตอบโจทย์ เพราะมีการจัดประเภทและตัดบางเคสออกจากคิวงาน ส่วนการแก้ฐานข้อมูลโดยตรงไม่มีขั้นตอนตรวจสอบและติดตามที่ครบถ้วน

## พฤติกรรม

- ผู้ใช้เลือกไฟล์และดูผลตรวจสอบก่อนยืนยัน แสดงจำนวนรายการใหม่ คู่เดิมที่ตรงกัน คู่ที่ขัดแย้ง รายการที่มี PET รอ และรายการรอ PET โดยไม่แก้ข้อมูลในขั้นตรวจสอบ
- เก็บเลขเป็นข้อความ ตรวจรูปแบบและความสัมพันธ์ของวันที่และลำดับ โดยรักษาศูนย์นำหน้า ระบุแถวผิดรูปแบบและรายการซ้ำในไฟล์
- ข้ามคู่เดิมที่ตรงกันได้อย่างปลอดภัยและทำซ้ำได้ หาก LN หรือ LN Halos จับคู่ขัดแย้งกัน ให้พักรายการและแสดงเหตุผล ห้ามเลือกผู้ชนะหรือเขียนทับเลขที่ออกแล้ว
- บันทึกคู่ที่ยืนยันพร้อมที่มาและประวัติผู้ดำเนินการ แล้วจับคู่ PET ที่รอโดยอัตโนมัติด้วย LN รักษา LN Halos ที่ออกภายนอกก่อนขั้นตอนรับ PET ไม่ออกเลขใหม่แทน
- เมื่อจับคู่ PET สำเร็จ บันทึกเหตุการณ์รับจาก HIS ตามเส้นทางจริงของระบบ ให้สถานะที่ผู้ใช้เห็นเป็น **รับจาก HIS** สร้าง attempt ที่พร้อมทำงาน และให้รายการเข้าสู่คิว Task List เมื่อผ่านกฎความปลอดภัยที่มีอยู่ ไม่สร้างหลักฐานการตรวจหรือผลที่ไม่ได้เกิดขึ้น
- ใบขอตรวจและใบยินยอมของรายการชุดนี้เป็นกระดาษตามที่ Owner แจ้ง บันทึกช่องทางดังกล่าวโดยไม่สร้างลายเซ็นหรือเอกสารปลอม และไม่ลบล้างการปฏิเสธหรือถอนความยินยอมที่บันทึกไว้
- ถ้า PET ยังไม่มา เก็บคู่เลขไว้และจับคู่อัตโนมัติเมื่อ PET มาถึง โดยใช้หลักการเดียวกันและไม่ให้การรับ PET ปกติออกเลขใหม่ก่อนสงวนเลขเดิม
- อัปเดตตัวนับรายเดือนให้ไม่น้อยกว่าเลขสูงสุดที่สงวนและไม่ลดค่าที่มีอยู่ ใช้การล็อกร่วมกับตัวออกเลขเพื่อป้องกันการชนระหว่างนำเข้าและออกเลขพร้อมกัน และไม่เปลี่ยนเลขเดิม
- แสดงผลหลังดำเนินการแยกนำเข้าสำเร็จ จับคู่สำเร็จ รอ PET และรายการขัดแย้งหรือทำไม่สำเร็จ พร้อมเหตุผลที่ตรวจสอบต่อได้

## ขอบเขตและการตรวจสอบ

รักษาข้อจำกัดสิทธิ์ การตรวจสอบย้อนหลัง ความถูกต้องของ migration การสำรองและกู้คืน และการแยกสภาพแวดล้อม HIS/NAS โดยไม่ส่งผลหรือไฟล์ออก HIS การเปลี่ยนฐานข้อมูลใช้ migration ใหม่เท่านั้น ทดสอบด้วยข้อมูลสังเคราะห์ทั้งกรณีซ้ำ ขัดแย้ง PET มาถึงก่อนและหลัง การออกเลขพร้อมกัน สถานะรับจาก HIS กระดาษ และการแสดงรายการพร้อมทำ Task List รวมถึงกรณีที่ติดเงื่อนไขความปลอดภัยที่มีอยู่

การนำไปใช้ Production และการนำเข้าข้อมูลจริงต้องผ่านขั้นตอน release และการสำรองที่โครงการกำหนด ไม่ถือว่าทดสอบสำเร็จหากบริการหรือหลักฐานที่จำเป็นไม่พร้อม
