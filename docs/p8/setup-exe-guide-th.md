# คู่มือติดตั้ง NIPT-CBH แบบสั้น (Windows Server / เครื่องหลักของแล็บ)

> รุ่นทดลอง (Test environment) ใช้บัญชีผู้ใช้ทดสอบและข้อมูลสมมติเท่านั้น ยังไม่ใช่การใช้งานทางคลินิก
> ไฟล์ติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัลของ Windows (Authenticode) จึงอาจมีหน้าต่างเตือน SmartScreen ให้กด "ข้อมูลเพิ่มเติม" แล้ว "เรียกใช้อยู่ดี"

## ติดตั้ง (4 ขั้นตอน)

1. คัดลอกไฟล์ `NIPT-CBH-Setup-1.0.0.exe` ไปไว้ในเครื่องที่จะเป็นเซิร์ฟเวอร์ (เช่น Desktop) ไม่ต้องใช้อินเทอร์เน็ต
2. ดับเบิลคลิกไฟล์ แล้วกด **Yes** เมื่อ Windows ถามสิทธิ์ผู้ดูแลระบบ (UAC)
3. กดปุ่ม **ติดตั้ง** แล้วรอจนขึ้นหน้า "ติดตั้ง NIPT-CBH สำเร็จ" (ประมาณ 4–5 นาทีในเครื่องทดสอบ ขึ้นกับความเร็วดิสก์)
4. กด **เปิด NIPT-CBH ตอนนี้** หรือใช้ไอคอน **NIPT-CBH** บน Desktop

ไม่ต้องพิมพ์คำสั่ง ไม่ต้องติดตั้ง Node.js / PostgreSQL เอง ระบบเริ่มทำงานเองหลังติดตั้งและหลังเปิดเครื่องใหม่ (หลังผู้ใช้เข้าสู่ Windows ในโหมดมาตรฐาน)

## เครื่องพยาบาล / แล็บเปิดใช้งานอย่างไร

หน้าสุดท้ายของตัวติดตั้งแสดง **ที่อยู่สำหรับทุกเครื่องในโรงพยาบาล** (เช่น `https://192.168.x.x`) ที่ตรวจแล้วว่าเปิดได้จากเครื่องเซิร์ฟเวอร์ กดปุ่ม **คัดลอก URL** ได้
เครื่อง ANC และ Lab พิมพ์ที่อยู่นี้ใน Browser (Chrome / Edge) ได้เลย ไม่ต้องติดตั้งโปรแกรมเพิ่ม

- ครั้งแรก Browser จะเตือนเรื่องใบรับรอง เพราะเป็นใบรับรองที่ระบบสร้างเอง ให้ตรวจว่าที่อยู่ตรงกัน แล้วเลือกดำเนินการต่อ หรือให้ IT ติดตั้งไฟล์ใบรับรอง (`/.well-known/nipt-cbh-certificate.cer` บนที่อยู่เดียวกัน) ในเครื่องผู้ใช้
- เครื่องเซิร์ฟเวอร์ควรใช้ IP คงที่ (หรือชื่อ DNS ภายในโรงพยาบาล) ถ้า IP เปลี่ยน ให้เปิดเมนู Start → NIPT-CBH → **ตั้งค่าที่อยู่ LAN และใบรับรอง (Set-LAN)**
- ระบบเปิดพอร์ต HTTPS ใน Windows Firewall เฉพาะเครือข่ายภายใน (Domain / Private และเฉพาะ Subnet เดียวกัน) พอร์ตฐานข้อมูลไม่เปิดออกนอกเครื่อง

## ถ้ามีข้อความ "สิ่งที่ต้องทราบ / ตั้งค่าเพิ่ม"

ตัวติดตั้งรายงานตามจริง เช่น ไม่พบ Microsoft Excel / ยังไม่มีเครื่องพิมพ์เริ่มต้น (ระบบหลักใช้ได้ แต่ฟังก์ชันสร้าง PDF จาก Excel ยังไม่พร้อม) หรือไม่ได้เปิดพอร์ต Firewall (เมื่อไม่ได้ใช้สิทธิ์ผู้ดูแลระบบ)

## ตรวจสถานะ / ตั้งค่าภายหลัง

- Start → NIPT-CBH → **ตรวจสถานะระบบ (Status)**
- ตั้งค่า HIS / ไฟล์ผลลัพธ์ / ที่เก็บสำรอง / รูปภาพ: เมนู Settings ในระบบ (ผู้ดูแลระบบ) ตามเดิม
- ข้อมูลเข้าสู่ระบบของผู้ใช้ทดสอบอยู่ในไฟล์ `credentials.txt` ในโฟลเดอร์ติดตั้ง (เปิดได้เฉพาะผู้ติดตั้ง)

## เปิดตัวติดตั้งซ้ำ / อัปเกรด / ถอนการติดตั้ง

- เปิดไฟล์ติดตั้งเดิมซ้ำ: ระบบ **ไม่สร้างฐานข้อมูลใหม่** แสดงที่อยู่เดิมและตรวจว่าระบบทำงานอยู่
- ไฟล์ติดตั้งเวอร์ชันใหม่กว่า: อัปเกรดทับโดยเก็บข้อมูลเดิม (สำรองข้อมูลก่อนอัปเกรดอัตโนมัติ ถ้าไม่สำเร็จระบบเดิมยังทำงานต่อ)
- ถอนการติดตั้ง: Settings → Apps → NIPT-CBH (หรือ Start → NIPT-CBH → ถอนการติดตั้ง) ค่าเริ่มต้นคือ **เก็บฐานข้อมูลและไฟล์ผู้ป่วยไว้** จะลบทั้งหมดเฉพาะเมื่อยืนยัน "ลบข้อมูลทั้งหมด" สองครั้ง

## ปัญหาที่พบบ่อย

| อาการ | ทำอย่างไร |
|---|---|
| ติดตั้งไม่ผ่านพร้อมข้อความภาษาไทย | อ่านข้อความ (บอกสาเหตุ เช่น พื้นที่ดิสก์ไม่พอ พอร์ตถูกใช้) แก้แล้วเปิดตัวติดตั้งใหม่ ข้อมูลเดิมไม่ถูกลบ รายละเอียดทางเทคนิคอยู่ที่ `C:\ProgramData\NIPT-CBH\setup-logs` |
| อัปเกรดแจ้งว่ามีงานเบื้องหลังค้าง | รอประมาณ 15 นาทีแล้วเปิดตัวติดตั้งอีกครั้ง ระบบเดิมยังทำงานอยู่ |
| เครื่องอื่นเปิด URL ไม่ได้ | ตรวจว่าอยู่เครือข่ายเดียวกัน / Windows Firewall มีกฎ NIPT-CBH / เครือข่ายของเซิร์ฟเวอร์ไม่ใช่ประเภท Public / IP ตรงกับที่ตั้งไว้ (ใช้ Set-LAN) |
